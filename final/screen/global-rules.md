# GLOBAL IMAGE RULES

## Mục tiêu

Mọi hình ảnh trong toàn bộ bộ truyện phải có phong cách thống nhất.

Không được thay đổi phong cách giữa các chương.

Mỗi ảnh phải giống như được vẽ bởi cùng một họa sĩ.

Không được tạo ảnh bán hiện thực.

Không được tạo Splash Art.

# Tỷ lệ khung hình truyện tranh

## Định dạng tổng

Truyện đăng dạng **Webtoon dọc (Vertical Scroll)** — một cột — đọc từ dưới lên.

| Kích thước | Tỷ lệ | Ghi chú |
|---|---|---|
| **800 × 1280 px** | **5:8** — (1:1.6) | Chuẩn — mỗi ảnh = một scroll unit |
| 1080 × 1920 px | 9:16 | Variant mobile |

## Kiểu khung trong một scroll unit

### Full Frame

```
┌──────────────────────┐
│                      │
│   800 × 1280         │  ← Một ảnh chiếm toàn bộ scroll
│   Tỷ lệ 5:8          │     Dùng cho: establishing, cao trào,
│                      │     cảnh rộng, kết PC
└──────────────────────┘
```

### Half-Split Ngang

```
┌──────────────────────┐
│ ┌────────────────────┐│
│ │  KHUNG TRÊN        ││  ← 800 × ~700 (5:4.4)
│ │  (ngang lớn)       ││     Đối thoại, hành động
│ └────────────────────┘│
│ ┌────────────────────┐│
│ │  KHUNG DƯỚI        ││  ← 800 × ~480 (5:3)
│ │  (ngang vừa)       ││     Reaction, đáp trả
│ └────────────────────┘│
└──────────────────────┘
```

### Khung Chính + Khung Nhỏ

```
┌──────────────────────┐
│ ┌────────────────────┐│
│ │  KHUNG CHÍNH       ││  ← 800 × ~900
│ │  (hành động)       ││     Chi tiết chính
│ └────────────────────┘│
│ ┌────────────────────┐│
│ │  KHUNG NHỎ         ││  ← 800 × ~280 (5:1.75)
│ │  (close-up)        ││     Cận mặt / chi tiết
│ └────────────────────┘│
└──────────────────────┘
```

### Ống dọc (cột hẹp)

```
┌──────────────────────┐
│ ┌──────┐             │
│ │      │             │
│ │CỘT   │             │  ← ~380 × ~1200 (1:3.2)
│ │DỌC   │             │     Chân dung, toàn thân,
│ │      │             │     bí ẩn, suy tư
│ └──────┘             │
└──────────────────────┘
```

## Nguyên tắc chọn khung

| Loại ảnh | Kiểu khung | Tỷ lệ | Lý do |
|---|---|---|---|
| Establishing shot — mở PC | Full Frame | 5:8 | Cho người đọc thấy không gian |
| Kết PC | Full Frame | 5:8 | Để lại ấn tượng cuối |
| Đối thoại — qua lại | Half-split | Trên 5:4.4 / Dưới 5:3 | Người nói + người nghe |
| Hành động — freeze | Full Frame | 5:8 | Giữ sức nặng khoảnh khắc |
| Chiến đấu — động | Khung chính + nhỏ | 900 + 280 | Hành động + reaction |
| Cảm xúc — cận mặt | Ống dọc hoặc ngang nhỏ | 1:3.2 hoặc 5:2 | Focus mắt, biểu cảm |
| Tư duy — sơ đồ | Full Frame | 5:8 | Visual thinking |
| Cảnh đông người | Full Frame | 5:8 | Scale — tương phản |

## Quy tắc scroll

- **Scroll unit đầu PC**: Full Frame — establishing
- **Scroll unit cuối PC**: Full Frame — hoặc khung cuối rộng
- **Không split ngang cho hành động cao trào** — giữ nguyên Full Frame
- **Không split dọc** (hai cột) trừ khi so sánh trực diện rất cần thiết
- Mỗi file `.md` = một scroll unit
